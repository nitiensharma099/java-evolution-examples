# java-evolution-examples

📘 **About**

This repository demonstrates the evolution of Java by highlighting major language and API enhancements introduced in each version, from Java 8 onward. It’s designed for developers who want to understand modern Java features through simple, hands-on examples. Each version’s folder includes well-documented code, explaining both syntax and practical use cases.

🧩 **Version-wise Feature Breakdown**

**Java 8**

Lambda Expressions
Functional Interfaces
Streams API
Optional Class
Default & Static Methods in Interfaces
Date and Time (java.time API)

**Java 9**

Module System (Project Jigsaw)
Private Methods in Interfaces
Factory Methods for Collections (List.of(), Set.of(), etc.)
Stream API Enhancements (takeWhile, dropWhile, iterate)

**Java 10**

Local Variable Type Inference (var)
CopyOf Collection Methods

**Java 11**
String API Enhancements (isBlank(), lines(), strip())
HTTP Client API (Standardized)
File Methods (readString(), writeString())

**Java 12 – 14**

Switch Expressions (preview → standard in Java 14)
Text Blocks (introduced in 13, finalized in 15)
Helpful NullPointerExceptions

**Java 15 – 17**

Sealed Classes
Records
Pattern Matching for instanceof
New Garbage Collectors (ZGC, Shenandoah)

**Java 18 – Latest**

Simple Web Server (JEP 408)
UTF-8 by Default
Pattern Matching for Switch (JEP 441)
Record Patterns (JEP 440)
Virtual Threads (Project Loom, Java 21)
